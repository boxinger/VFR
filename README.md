# VFR 控制器频响设计器

VFR 是一个基于 PySide6 和 PyQtGraph 的桌面控制器设计工具。它从用户明确映射的 CSV 读取功率通路频率响应，实时显示功率通路、控制器和环路三组 Bode 图，并计算交越频率与稳定裕度。

## 启动

项目使用 Python 3.14 和 uv：

```powershell
$env:UV_CACHE_DIR = 'D:\Project\VFR\.uv-cache'
uv sync --locked
uv run vfr
```

也可以运行：

```powershell
uv run python main.py
```

## 使用流程

1. 点击“打开 CSV”。
2. 明确选择频率列、响应形式以及两列响应数据。
3. 导入后在左侧添加实零点、实极点或原点零极点。
4. 使用“编辑零极点”模式水平拖动控制器图中的标记。
5. 使用“调整增益”模式在控制器增益图中上下拖动。
6. 在左侧查看首次增益交越、相位裕度、增益裕度和多重交越提示。

## CSV 契约

- 编码固定为 UTF-8，分隔符固定为英文逗号。
- 第一非空行必须是唯一、非空的表头。
- 小数点使用 `.`，允许普通数字和科学计数法。
- 频率固定为 Hz，相位固定为 degree，单元格中不写单位。
- 一个文件视为一组响应；未映射列全部忽略，`module`、`mode`、`status` 等名称没有特殊含义。
- 导入时必须明确选择以下一种组合：dB/相位、线性幅值/相位、实部/虚部。
- 允许频率乱序，导入后会排序；重复频率直接拒绝。
- 软件不校验数据物理合理性，也不会自动展开或修正用户相位。

最小幅相 CSV：

```csv
frequency_hz,gain_db,phase_deg
1.000000e+01,2.593263e+01,-1.178283e+00
1.000000e+02,2.580000e+01,-8.300000e+00
```

最小实虚部 CSV：

```csv
frequency_hz,real_component,imaginary_component
1.000000e+01,1.979428e+01,-4.071250e-01
1.000000e+02,1.950000e+01,-2.900000e+00
```

导入映射可以保存为模板。模板位于 Qt 的应用配置目录，不写入 CSV。

## 控制器定义

第一版采用归一化 Bode 形式：

\[
C(s)=\operatorname{sign}(K)|K|
\left(\frac{1}{s}\right)^{n_i}
\left(s\right)^{n_d}
\frac{\prod(1+s/\omega_z)^{m_z}}
{\prod(1+s/\omega_p)^{m_p}}
\]

其中参考角频率为 `1 rad/s`。有限零极点使用归一化因子，`K` 与 dB 满足：

\[
G_K=20\log_{10}|K|
\]

修改 dB 时保留 `K` 的符号。第一版 UI 支持实零极点、原点零极点和重数；核心模型已经为复共轭二阶环节保留扩展能力。

## 第一版边界

不包含多数据集叠加、相位展开、自动补偿设计、数字控制器、工程保存、控制代码导出或 EXE 打包。环路固定为 `L = Gp × C`，不额外加入反馈、ADC、PWM 或延迟模型。
