# VFR 控制器频响设计器

VFR 是一款桌面控制器设计工具。软件读取功率通路的频率响应 CSV 数据，同时显示功率通路 \(G_p\)、控制器 \(C\) 和环路 \(L=G_pC\) 的 Bode 图，并实时计算交越频率、相位裕度和增益裕度。

## 安装与启动

运行环境：

- Python 3.14
- uv

在项目目录中同步依赖并启动软件：

```powershell
$env:UV_CACHE_DIR = 'D:\Project\VFR\.uv-cache'
uv sync --locked
uv run vfr
```

也可以通过入口脚本启动：

```powershell
uv run python main.py
```

## 使用方法

1. 打开 CSV 文件。
2. 选择频率列、响应形式和对应的响应数据列。
3. 确认导入后，在左侧控制面板中添加零点或极点。
4. 通过数值输入或图形拖动调整零极点频率和控制器整体增益。
5. 查看功率通路、控制器和环路的增益及相位响应。
6. 在左侧控制面板中查看交越频率和稳定裕度。

## 图形交互

软件提供四种操作模式：

| 快捷键 | 操作 | 说明 |
| --- | --- | --- |
| `Q` | 打开 CSV | 选择并导入功率通路频率响应 |
| `W` | 缩放与平移 | 调整 Bode 图的显示范围 |
| `E` | 编辑零极点 | 水平拖动控制器图中的零极点标记 |
| `R` | 调整增益 | 在控制器增益图中上下拖动曲线 |

当数值或文本输入框获得焦点时，快捷键不会触发，用户可以正常输入科学计数法。

控制面板中的频率支持 Hz 与 rad/s 双向换算；修改任意一项时，另一项同步更新。整体增益支持 \(K\) 与 dB 双向换算。

## CSV 格式

CSV 文件须满足以下要求：

- 使用 UTF-8 编码和英文逗号分隔符。
- 第一个非空行必须是表头，各表头名称不能为空且不能重复。
- 小数点使用 `.`，允许普通数字和科学计数法。
- 频率单位固定为 Hz，相位单位固定为 degree，单元格内不写单位。
- 每个文件作为一组频率响应导入，未选择的列会被忽略。
- 导入时必须明确选择一种响应形式：dB/相位、线性幅值/相位或实部/虚部。
- 频率可以乱序，导入后按升序排列；同一文件中不能包含重复频率。
- 软件使用 CSV 中提供的相位，不进行相位展开或自动修正。

### dB 与相位

```csv
frequency_hz,gain_db,phase_deg
1.000000e+01,2.593263e+01,-1.178283e+00
1.000000e+02,2.580000e+01,-8.300000e+00
```

### 线性幅值与相位

```csv
frequency_hz,magnitude,phase_deg
1.000000e+01,1.979847e+01,-1.178283e+00
1.000000e+02,1.971802e+01,-8.300000e+00
```

### 实部与虚部

```csv
frequency_hz,real_component,imaginary_component
1.000000e+01,1.979428e+01,-4.071250e-01
1.000000e+02,1.950000e+01,-2.900000e+00
```

导入时选择的列名和响应形式可以保存为模板。再次导入相同结构的 CSV 时，可以载入模板并确认映射。

## 控制器定义

控制器采用归一化 Bode 形式：

\[
C(s)=K
\left(\frac{\omega_r}{s}\right)^{n_i}
\left(\frac{s}{\omega_r}\right)^{n_d}
\frac{\displaystyle\prod_j\left(1+s/\omega_{z_j}\right)^{m_{z_j}}}
{\displaystyle\prod_k\left(1+s/\omega_{p_k}\right)^{m_{p_k}}},
\qquad \omega_r=1\ \mathrm{rad/s}
\]

其中：

- \(K\) 为有符号整体增益。
- \(\omega_{z_j}\) 为有限零点角频率。
- \(\omega_{p_k}\) 为有限极点角频率。
- \(m_{z_j}\)、\(m_{p_k}\) 为对应有限零极点的重数。
- \(n_i\) 为原点极点重数，\(n_d\) 为原点零点重数。
- \(\omega_r\) 为参考角频率，固定为 \(1\ \mathrm{rad/s}\)。

有限零极点采用 \(1+s/\omega\) 形式，因此移动有限零极点不会改变其低频增益。整体增益与 dB 的关系为：

\[
G_K=20\log_{10}|K|
\]

修改 dB 时保留 \(K\) 的符号，\(K=0\) 不可用。

## 环路与稳定裕度

环路响应按照下式计算：

\[
L(j\omega)=G_p(j\omega)C(j\omega)
\]

软件在功率通路的原始频率范围内计算环路，不对功率通路进行范围外推。交越位置根据相邻频点在对数频率轴上插值得到。

存在多个增益交越点时，界面显示最低频交越点的主要指标，并提示多重交越及最差裕度。稳定裕度用于辅助判断环路设计，不等同于对系统稳定性的完整证明。

## 功能范围

当前支持：

- 单组功率通路频率响应。
- 有限实零点和实极点。
- 原点零点和原点极点。
- 正整数零极点重数。
- 控制器整体增益调整。
- CSV 导入映射模板。
- 功率通路、控制器和环路 Bode 图同步显示。

当前不包含多数据集叠加、相位展开、自动补偿设计、数字控制器、工程保存、控制代码导出和可执行文件打包。环路采用单位反馈模型，不额外包含反馈网络、ADC、PWM 或延迟模型。
